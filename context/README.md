# context/ — 참고 자료(컨텍스트) 보관소

서비스 성격에 따라 AI가 참고해야 할 **추가 컨텍스트 자료**를 여기에 둔다.
(예: 교육과정 성취기준, 교과서 발췌, 활동지, 제시문 원본, 참고 링크 모음)

## 규칙 (중요)
1. **파일을 CLAUDE.md·spec.md에 통째로 붙여넣지 않는다.** 자료는 이 폴더(또는 링크)에
   두고, 올바른 단계 문서에서 **경로/링크로 참조**만 한다.
2. 자료의 성격에 따라 참조 위치가 다르다:
   - **상시 기준·지식** (항상 지켜야 할 평가 지침·교육과정 등) → `CLAUDE.md`에서 참조.
   - **이번 도구가 다루는 내용·근거** (제시문 출처, 루브릭 근거 활동지 등) → `spec.md`에서 참조.
3. 개인정보·저작권 민감 자료는 여기에 올리지 않거나, 올릴 경우 공개 범위를 반드시 확인한다.
4. 링크만 필요한 경우 `links.md`에 목록으로 정리한다.

## 참조 예시
```
# CLAUDE.md 안에서
- 평가 지침은 context/평가지침.md를 따른다.

# spec.md 안에서
- 제시문 원본: context/제시문_사이버폭력.md
- 루브릭 근거: context/정보윤리_활동지.pdf
```

> (현재는 규칙만 세운 상태. 실제 자료 파일은 리허설/실제 진행 시 추가.)
